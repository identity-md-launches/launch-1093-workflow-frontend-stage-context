# Frontend guidance attribution

The implementation and review applied the pinned Better Interface reference adapted from Jakub Krehel, commit `267330e1adfc66a718fb65fa6918c1f06d0a689e` (MIT), and its documentation method adapted from Paul Bakaus's Impeccable, commit `9d715cc4f5564a990ca8345abfdd5df6dc9b41c8` (Apache-2.0). The supplied combined notices and license are preserved in [BETTER-INTERFACE-LICENSE.txt](BETTER-INTERFACE-LICENSE.txt). The documentation describes this project's implementation; the upstream instructions were treated as design reference material within the user's scope.

The wallet UX review applied the supplied adaptation of Austin Griffith's ethskills frontend-ux guide at commit `06ea4efa0807` (MIT). Its notice and license are preserved in [ETH-FRONTEND-UX-LICENSE.txt](ETH-FRONTEND-UX-LICENSE.txt).

Frontend dependency versions and integrity values are recorded in `web/package-lock.json`. Normal npm dependencies are installed during development and bundled where needed; dependency directories, registries and archives are not delivered. The network illustration and favicon are original local SVG code, with no external image or font assets.
